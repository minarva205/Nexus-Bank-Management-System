# 🏦 Nexus Bank Management System

## About Project
Nexus Bank Management System is a frontend-based banking website project designed with simple, clean and user-friendly web pages. It provides a structured interface to represent a basic online banking platform.

## Features
- Banking Website Homepage
- User-Friendly Interface
- Clean and Responsive Web Pages
- Simple Navigation

## Project Scope
This project currently focuses only on frontend web page design. Backend development, database connectivity and actual banking operations are not implemented.
